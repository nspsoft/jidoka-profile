- 2026-09-18: Implementasi backend M2 menggunakan Express + MySQL (Laragon mysql2/promise) + Nodemailer + JWT + Multer. Lapisan data src/data/db.js mengadopsi pola dual adapter (remote-first dengan fallback local storage). Autentikasi server JWT menggantikan sessionStorage dan password hardcoded lama. Penambahan static prerendering build script (scripts/prerender.js) murni Node.js (0 dependensi runtime baru) yang menghasilkan file HTML statis lengkap per route di dist/ agar konten inti terbaca via View Source. Otomasi pembuatan public/sitemap.xml (15 URLs) dan public/robots.txt saat build. Preconnect gstatic ditambahkan di index.html.
