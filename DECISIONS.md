- 2026-10-30: Optimasi Aksesibilitas & Performa Mobile (M4-6 & M4-7): Peningkatan kontras teks WCAG AA di footer dan Japanese Kanji tag tur pabrik (rasio > 4.5:1), perbaikan heading-order `h3` di footer, penambahan dimensi eksplisit `width`/`height` pada elemen gambar logo & kartu produk, non-blocking asynchronous preloading Google Fonts, serta deferment buffer video hero (`preload="metadata"` + `requestIdleCallback`) sehingga LCP mobile turun dari 3.9 detik menjadi ~1.2 detik. - 2026-11-01: Security Hardening & Vulnerability Remediation (M4-8):
  - Penambahan rate limiting anti brute-force pada endpoint `/api/auth/login` (maksimal 10 percobaan per 15 menit per IP).
  - Peningkatan kebijakan password: minimal 8 karakter dengan kombinasi huruf dan angka.
  - Implementasi *strict whitelist* ekstensi file pada `/api/upload` (hanya gambar, dokumen kerja, PDF, dan video; blokir `.php`, `.exe`, `.sh`, `.html`) serta sanitasi anti-XSS pada file SVG.
  - Sanitasi `escHtml()` dan pembatasan jumlah & ukuran field payload pada formulir leads/RFQ untuk mencegah HTML injection dan memory exhaustion pada notifikasi email.
  - Pembatasan whitelist nama koleksi pada `/api/content/:collection` untuk mencegah pencemaran tabel database.
  - Implementasi HTTP Security Headers (`X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin`, CSP sandbox pada static `/uploads`), pembatasan CORS ke domain resmi, dan mematikan `X-Powered-By: Express`.
  - Peningkatan escaping pada fungsi frontend `esc()` dengan penambahan sanitasi karakter petik tunggal (`'`).
- 2026-11-01: Admin CMS Hero Video Direct Upload (M4-9): Penambahan fitur upload video hero beranda langsung dari komputer pengguna ke server backend via `/api/upload` (batas 100 MB, format MP4/WebM) pada tab Konten Beranda -> Banner Hero & Background serta tab Kontak & Akses. Dilengkapi tombol reset ke `factory.mp4`, feedback progress upload aman, dan sinkronisasi live preview interaktif secara otomatis.
